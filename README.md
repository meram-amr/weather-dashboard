# Weather Dashboard — Real-Time Weather Application

A real-time weather dashboard that fetches live data using the OpenWeatherMap API. Users can search for any city or use their current location to view weather conditions instantly.

## Live Demo

[View Live](https://meram-amr.github.io/weather-dashboard/)

---

## Features

* Search weather by city name
* Detect user location using Geolocation API
* Display temperature, humidity, wind speed, and conditions
* 3-day weather forecast
* Loading states during API requests
* Clean dark-themed user interface

## Getting Started

```bash id="z8x2pl"
# 1. Clone the repository
git clone https://github.com/meram-amr/weather-dashboard.git

# 2. Open index.html in your browser
```

Note: You need an API key from https://openweathermap.org/api.
Replace `YOUR_API_KEY` in `script.js` with your own key.
